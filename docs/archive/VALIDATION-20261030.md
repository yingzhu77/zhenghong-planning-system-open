本页说明当前检查入口、验收边界和最近已完成的验证。源码测试、隔离数据库／浏览器、真实模型、正式发布和业务验收分别记录；其中一步通过不能代替其余步骤。实际运行镜像、受控备份、人员核验及发布回执保存在私有当前状态入口，不写入源码文档。

## 检查入口

```sh
npm run check:source
git diff --check
npm test
npm run test:db
```

`npm test` 使用仓库定义的顺序执行完整测试及综合渲染脚本。完整输出须保留退出状态，不能把过滤后的通过行当成整套通过。定向验证可运行对应 `tests/*.test.mjs`，但交付须明确覆盖范围。新源码、测试和文档先审阅内容，再加入 `.gitignore` 精确白名单；`check:source` 不替代人工内容检查。

所有可能写数据库的测试显式使用可丢弃的隔离实例、匿名账号及临时上传目录，不继承真实 `.env`。事务、唯一约束、行锁和并发须用实际 PostgreSQL 核对，不能只凭模拟数据库证明。真实AI调用需显式受限配置，默认使用匿名材料；用户明确授权的企业样表仅经既有应用链路测试预览，严禁未经授权保存或导入，不读取或输出独立密钥。
