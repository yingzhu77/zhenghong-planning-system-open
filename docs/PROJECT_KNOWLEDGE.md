# 方案资料中心

项目档案按方案资料提供项目速览、指标与专题、版本与待核对三个入口。检索范围为关键摘录、概要和差异，不提供完整原件打开、下载或全文逐页查询。主题根据已有摘录动态生成，工作用途筛选不授予项目或专业权限。没有方案索引的旧项目继续使用原档案；有索引的项目保留原档案维护入口，但不能借旧入口读取受保护原件。

## 数据与来源

内部保留`project_master.fields.scheme_catalog`版本`1`，不增加数据库迁移。它保存完整来源和索引用于受控维护，浏览器读取的是后端生成的公开摘录投影：

- `source`：只保留原文件名；原件URL和SHA256不下发。
- `kind`、`scope`、`edition`、`summary`：方案类型、实际范围、版本及概要。
- `facts`：`label`、`value`、`unit`、`page`、`group`、`scope`、`note`、`audiences`、`status`、`highlight`。缺失值显示“未载明”，不代填零。
- `pages`：公开响应为空数组，不发送整页提取文字。`page_numbers`保留合法物理页号，`page_count`表示索引覆盖页数，不能当作完整PDF总页数。
- `issues`：差异标题 `title`、说明 `detail`、来源页码数组 `pages`。
- `preview`与`plan_page`：已登记的固定关键区域接口及原物理页码。总览点击已批准的关键图可全屏查看同一裁剪图。无合格关键图时提示不可用。

不同阶段、不同地块和不同统计口径分别保存，不能因文件名相似自动合并或累加。方案摘录不代表最终批复、建成或验收结论。

索引展示前检查结构，稀疏摘录按登记的正整数PDF物理页码显示来源，不按数组位置编号。来源为文字，不生成原件链接。异常索引不会改写原数据，页面提示暂无法读取并回到原档案。保存原档案其他字段时，服务器保留原有完整方案索引，避免用公开投影覆盖内部数据；索引更新通过受控资料交接完成。

## 权限和本地资料

索引从已有权限查询结果中读取，只索引当前账号可见项目。`/api/scheme-previews/:project/:sha.webp`只服务该项目已登记的真实裁剪图，沿用身份、项目权限及管理查看规则。旧`/api/files/drawings/...`原件和整页图链接由后端拒绝；普通独立图纸、周报附件和资料共享不扩大禁用。加密格式、受控登记、离线准备及密钥管理见[方案原件保护](SCHEME_PROTECTION.md)。

真实文件、提取结果、导入脚本、截图与人员映射不得进入源码仓库。资料整理后应先在隔离本地库检查 SHA256、范围、页码与刷新回读，不自动匹配人员，不修改成员权限。生产项目的资料归属和工业等类型映射需另行确认。

## 验证与升级

相关检查：`tests/project-knowledge.test.mjs`、`tests/scheme-protection.test.mjs`、`tests/scheme-vault.test.mjs`、`tests/scheme-materials.test.mjs`及旧档案、富文本、文件和HTTP集成测试。集成测试使用独立匿名PGlite实例。

浏览器验收覆盖桌面与窄屏、别名、授权项目范围、专题与用途、摘录查询、空结果、长备注、纯文本来源、版本差异、旧档案和刷新回读。必须验证已知原件链接及直接接口仍拒绝、浏览器不收到全文，且没有关键图时明确提示不可用。

源码更新不自动导入材料或加密现有运行文件。需要先按受控清单生成密文和批准关键图，核验后按发布流程部署；原始JSON字段与其他档案保留。不能回退到允许完整原件读取的旧代码来修复预览故障。数据库、上传卷及独立密钥按受控流程备份，不得删卷升级。

源码及本地匿名测试不代替实际材料准备、项目映射、批准裁剪和上线核验；具体实例版本与验证证据由受控状态入口记录。
