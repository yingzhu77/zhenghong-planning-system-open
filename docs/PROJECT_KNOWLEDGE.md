# 方案资料中心

项目档案可根据方案资料提供项目速览、指标与专题、原文检索、版本与待核对四个入口。主题根据已有摘录动态生成，工作用途仅用于检索筛选，不授予项目或专业权限。没有方案索引的旧项目继续使用原档案；有索引的项目也保留原档案维护入口。

## 数据与来源

复用 `project_master.fields.scheme_catalog`，版本为 `1`，不增加数据库迁移。结构包含：

- `source`：原文件名、SHA256、已登记的私有文件 URL。
- `kind`、`scope`、`edition`、`summary`：方案类型、实际范围、版本及概要。
- `facts`：`label`、`value`、`unit`、`page`、`group`、`scope`、`note`、`audiences`、`status`、`highlight`。缺失值显示“未载明”，不代填零。
- `pages`：PDF 物理页码 `page` 与提取文字 `text`。图片页未识别的内容须查看原 PDF，全文检索不能替代图纸核对。
- `issues`：差异标题 `title`、说明 `detail`、来源页码数组 `pages`。
- `preview` 与 `plan_page`：已登记私有总图缩略图及原页码。

不同阶段、不同地块和不同统计口径分别保存，不能因文件名相似自动合并或累加。方案摘录不代表最终批复、建成或验收结论。

## 权限和本地资料

索引从已有权限查询结果中读取，只索引当前账号可见项目。PDF 与预览复用 `/api/files/drawings/:project/:filename`、附件登记及 RLS 校验，不新增公开文件目录。前端还限制链接必须属于相同项目，并转义所有摘录文字。

真实文件、提取结果、导入脚本、截图与人员映射不得进入源码仓库。资料整理后应先在隔离本地库检查 SHA256、范围、页码与刷新回读，不自动匹配人员，不修改成员权限。生产项目的资料归属和工业等类型映射需另行确认。

## 验证与升级

相关检查：`tests/project-knowledge.test.mjs`、`tests/reporter-archive.test.mjs`、`tests/archive-rich-text.test.mjs`、`tests/api-integration.test.mjs`。集成测试使用独立匿名 PGlite 实例。

浏览器验收应覆盖桌面与窄屏、总建面别名、当前／所有有权项目、专题与用途、全文搜索、空结果、长备注、来源 PDF、版本差异、原档案回退及刷新回读。

部署源码只增加页面资源和可选数据读取，不自动导入任何资料或执行迁移。旧 JSON 字段和七类档案保留；回退源码后新索引仍存于 JSONB 中，旧界面忽略该字段。资料及附件需要随数据库、上传卷一并按既有受控流程备份；不得删卷升级。
